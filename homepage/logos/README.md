# Логотипы производителей

Нормализованный набор для логобара главной. Состав логобара задан ТЗ, стр. 384:
PUDU, GAUSIUM, KEENON, HIKROBOT, FORWARDX, UNITREE, ORIONSTAR + ссылка «и другие».

Исходники лежат в `assets/logos_official_bundle/` и **не менялись** — это источник правды.
Здесь их нормализованные копии.

## Как подключать

Монохромные SVG переведены на `currentColor`: один файл работает и на тёмной плите,
и на светлом фоне. Цвет задаётся через CSS родителя:

```css
.logobar { color: var(--on-stage); }   /* на подиуме */
.logobar { color: var(--ink-muted); }  /* на светлом */
```

Выравнивать логотипы надо **по оптической высоте знака, а не по высоте бокса**:
пропорции у брендов разные, при равной высоте контейнера HIKROBOT визуально вдвое
крупнее PUDU. Задавать высоту индивидуально на бренд.

их без правок. Оригинал, как скачался, параллельно класть в

правится никогда.

| 🔴 блокер | KEENON | `keenon.svg` или `keenon-white.png` | одноцветный белый знак — либо SVG, который можно перевести на `currentColor` | единственная дыра в логобаре: текущий `keenon.png` тёмный и многоцветный, на тёмной плите не читается |

Ничего из этого пока не сделано: в `index.html`, `styles.css` и `main.js` сейчас

## Что было сделано при нормализации

- Цвета монохромных знаков (`black`, `white`, `#040000`) заменены на `currentColor`.
- Замена применялась **только к видимой графике**. Секции `defs`, `clipPath`, `mask`,
  `pattern`, `filter`, градиенты — не тронуты: там `fill="white"` означает «непрозрачно»
  или задаёт форму отсечения, а не цвет. У PUDU белый `<rect>` внутри `<clipPath>` —
  это клип-маска, не подложка; у HIKROBOT четыре `<mask fill="white">`.
- Заглушки `keenon.svg`, `forwardx.svg`, `orionstar.svg` удалены — их вытеснили
  настоящие растры. Прежние семь файлов в этой папке были нарисованными от руки
  буквами, а не логотипами; в git они остались в истории.

## Проверено

Все SVG парсятся как XML, число путей совпадает с исходниками, знаки отрисовываются.
Правовое: файлы взяты с официальных доменов, но условия использования товарных знаков
у брендов различаются — перед публикацией свериться с Brand/Press Kit каждого.
