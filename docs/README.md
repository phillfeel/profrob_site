# docs/ — спеки, промпты, контент

Код сайта лежит в корне репозитория (ветка `gh-pages` отдаёт его оттуда), здесь только документы.
Перед миграцией на Next.js структуру корня не меняем.

| Папка | Что внутри | Статус |
|---|---|---|
| `content/` | Контент-ТЗ сайта (v2.1) | актуально |
| `specs/` | Спеки на конкретные страницы и прототипы | актуально |
| `prompts/` | Промпты для генерации картинок (роботы, кейсы) | актуально |
| `archive/` | Исходные материалы: legacy-дизайн, скриншоты, черновики | только для справки |

Рядом по смыслу: `design-system/` (токены и компоненты), `prototypes/` (песочницы `a` и `motion`),
`assets/cases_images/README.md` (правила для картинок кейсов).

**Правило:** новые спеки кладём в `specs/`, промпты в `prompts/`, контент в `content/`. В корне новых `.md` не создаём.
