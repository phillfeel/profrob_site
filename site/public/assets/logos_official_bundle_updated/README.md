# Логотипы производителей — исходники

Официальные логотипы, скачанные с доменов производителей. По одному файлу на бренд, как скачались.

**На сайте эти файлы не подключаются.** В вёрстке используются обработанные версии из `assets/brands/`:
обрезаны по краске и приведены к одному серому. Эта папка нужна, чтобы при необходимости обработать заново.

## Важно

Условия использования товарных знаков у брендов различаются. Перед публикацией на коммерческом сайте
сверьтесь с актуальным Brand/Press/Media Kit каждого производителя. Не меняйте пропорции и охранное поле
логотипов без разрешения бренда.
