# Badge

Бейдж-таблетка статуса с точкой: «Система онлайн» на лаймовой подложке и остальные состояния.

**Пропсы:** `tone` — `success` (`lime-soft` + точка `lime-ink` с лаймовым ореолом), `neutral`, `accent`, `warning`, `danger`, `lime` (сплошной лайм, `on-lime`) ; `dot={false}`.

- Статус всегда назван словом — цвет только подкрепляет.
- `lime` (сплошной) — максимум один на экран, для главной цифры-выгоды.
- Не делайте: бейджи-кнопки; больше двух бейджей подряд.
