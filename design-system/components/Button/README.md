# Button

Кнопка-таблетка: синяя главная для целевого действия, белая с обводкой для второстепенного.

**Варианты:** `primary` (заливка `accent`, текст `on-accent`) — одно целевое действие на экран: «Рассчитать ROI», «Связаться», «Отправить заявку». `secondary` (белая, обводка `line-strong`) — альтернатива рядом с primary: «Смотреть роботов». `ghost` — третичные действия и иконки. `inverse` (светлая заливка `on-stage`) — главное действие на тёмной сцене, когда синяя тонет в синем свечении.

**Размеры:** `lg` 52px — герой и CTA-блоки; `md` 44px — навигация, формы; `sm` 32px — внутри карточек.

**Пропсы:** `variant`, `size`, `icon` (имя из Icon: `arrow-right` для «вперёд», `arrow-up-right` для перехода на страницу), `iconOnly` (+ `aria-label`), `href` (рендерит `<a>`), остальное — атрибуты `<button>`.

- Делайте: глагол в начале, 1–3 слова, без точки. Стрелка → только у кнопок, ведущих дальше по воронке.
- Не делайте: две primary рядом; лаймовые кнопки (лайм — только сигнал); текст капсом.
