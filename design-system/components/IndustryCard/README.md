# IndustryCard

Кликабельная карточка отрасли: моно-индекс, круглая стрелка (синеет при наведении), название, одна строка задач и теги роботов.

**Пропсы:** `index`, `title`, `text`, `tags` (категории роботов), `href`.

- Вся карточка — ссылка; внутри не должно быть других интерактивных элементов.
- Сетка 3×2 или 4×2, одинаковая высота.
