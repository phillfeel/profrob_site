# ScanRing

Тонкий лаймовый эллипс сканирования под роботом на тёмной сцене.

**Пропсы:** `width` (высота = 22% ширины), `className` для позиционирования.

- Только на `stage` и под роботом — это «след лидара», не декор.
- Можно анимировать пульсацию opacity 0.5→1 за `duration-slow`, с учётом prefers-reduced-motion.
