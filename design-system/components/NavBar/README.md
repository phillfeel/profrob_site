# NavBar

Стеклянная навигация-«таблетка»: логотип слева, пять разделов по центру, синяя «Связаться» справа.

**Пропсы:** `links` — массив строк или `{label, href}` (по умолчанию «Решения, Роботы, Отрасли, Платформа, Кейсы»); `active` — подпись текущего раздела; `logo` (узел) или `logoSrc`; `ctaLabel`, `onCta`.

**Поведение:** `position: sticky; top: space-4` задаёт страница, не компонент. Ширина до `nav-max`, по центру контейнера. До 900px ссылки прячутся в меню-бургер, выпадающее белой карточкой `shadow-lg`.

- Делайте: держите фон страницы видимым сквозь стекло — это и есть эффект.
- Не делайте: больше шести пунктов; вторую кнопку рядом с «Связаться».
