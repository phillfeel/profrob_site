# Tag

Моноширинная метка категории в квадратных скобках с синей точкой: «[ • УБОРКА ]».

**Пропсы:** `children` — одно-два слова, компонент сам переводит в верхний регистр; `dot={false}` — без точки.

**Где:** над роботами на сцене героя, в углу медиа карточки робота, в карточках отраслей и кейсов. Это «приборный» слой — как подпись на схеме.

- Делайте: существительное категории («Уборка», «Склад»).
- Не делайте: статусы (для них Badge), фразы, призывы к действию.
