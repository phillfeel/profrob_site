# PartnerStrip

Ряд производителей белыми монохромными знаками на тёмной кромке подиума, разделённых вертикальными линиями `stage-line`.

**Пропсы:** `partners` — строки или `{name, src}`; `src` — белый монохромный логотип (SVG/PNG) партнёра.

- Логотипы партнёров берите из их официальных пресс-китов, в одноцветном белом варианте, высота 24px.
- Пока логотипов нет — названия набираются Onest 600 с разрядкой (как в превью).
