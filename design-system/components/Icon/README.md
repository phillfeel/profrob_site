# Icon

Линейная иконка 24×24, штрих 1.75, скруглённые концы — рисуется `currentColor`, наследует цвет текста.

**Пропсы:** `name` — `arrow-right`, `arrow-up-right`, `plus`, `minus`, `check`, `menu`, `close`, `chevron-down`, `play`, `phone`, `mail`; `size` (по умолчанию 20); `label` — если иконка несёт смысл без подписи.

- Размеры: 16 в `sm`-кнопках, 18–20 в интерфейсе, 24 отдельно.
- Набор минимальный и временный (см. «Иконография» в брендбуке): новые иконки берите из Lucide с тем же штрихом 1.75.
- Не заливайте иконки цветом и не кладите их в цветные кружки ради декора.
