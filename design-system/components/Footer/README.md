# Footer

Тёмный футер на графите `stage` со скруглёнными верхними углами `radius-xl`: логотип-инверсия и слоган, три колонки ссылок, юридическая строка.

**Пропсы:** `columns` — `[{title, links: [строка | {label, href}]}]`, `tagline`, `legal` (узел), `logo`/`logoSrc` (по умолчанию светлая версия логотипа).

- Контакты в футере — реальные и кликабельные (`tel:`, `mailto:`).
