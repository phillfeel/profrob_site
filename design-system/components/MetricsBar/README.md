# MetricsBar

Компактная стеклянная карточка «живых» метрик флота с лаймовым бейджем статуса — правый верхний угол героя.

**Пропсы:** `items` — `[{value, label}]`, 2–4 пункта, разделяются «·»; `status` — текст бейджа или `false`.

- Цифры — реальные данные платформы (подтягиваются из API), не маркетинговые.
- Числа с неразрывным пробелом и запятой: «98,2%», «1 240 м²».
