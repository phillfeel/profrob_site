# Kpi

Крупная цифра `stat-xl` с единицей в синем и подписью — для блоков «Результаты», ROI и кейсов.

**Пропсы:** `value` (строка — вы сами форматируете: «−38», «1 240»), `unit` (%, мес, м², ₽), `label` (до ~40 знаков).

- Минус — типографский «−», не дефис.
- В ряд 3–4 KPI, выравнивание по левому краю, зазор `space-12`.
- Значения в превью — пример оформления; на сайте только подтверждённые цифры.
