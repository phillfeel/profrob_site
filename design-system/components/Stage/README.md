# Stage

Графитовый подиум-сцена `stage` со скруглением `radius-xl` и синим свечением по кромке — тёмный блок внутри светлой страницы.

**Пропсы:** `glow` (по умолчанию `true`, тень `glow-edge`), `children`, `className`, `style`.

**Как работает:** Stage ставит `data-theme="dark"`, поэтому все компоненты внутри сами переключаются на тёмные значения токенов — отдельные «тёмные версии» не нужны.

**Где:** подиум героя с роботами, секция «Платформа», финальный CTA с формой. Не больше трёх сцен на странице, между ними — светлые секции.
