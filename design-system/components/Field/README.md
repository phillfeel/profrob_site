# Field

Поле ввода с подписью сверху, подсказкой или ошибкой снизу; однострочное или `multiline`.

**Пропсы:** `label`, `hint`, `error` (заменяет подсказку, красит обводку в `danger`, ставит `aria-invalid`), `multiline`, остальное — атрибуты `<input>`/`<textarea>`.

- Подпись — всегда видимая, плейсхолдер только пример.
- Ошибка говорит, как исправить: «Проверьте адрес — не хватает домена».
- Форма заявки: Имя, Телефон, Компания, Задача — не больше четырёх полей.
