# Segmented

Переключатель-таблетка из 2–5 вариантов: выбранный поднимается белой плашкой.

**Пропсы:** `options` (строки или `{value, label}`), `value`/`defaultValue`, `onChange`, `size` (`md` | `sm`), `label` (для скринридера).

**Где:** тип объекта в калькуляторе ROI, фильтр каталога роботов, вкладки секции «Платформа».
