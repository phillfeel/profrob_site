# CaseCard

Карточка кейса: клиент и отрасль, одна крупная синяя метрика результата, подпись, короткая история и состав флота моноширинным.

**Пропсы:** `client`, `industry` (тег), `metric` («−42%», «×2,4»), `metricLabel`, `text` (до 160 знаков), `robots`.

- Одна метрика на карточку — самая сильная и проверяемая.
- В превью — пример оформления, не реальный клиент.
