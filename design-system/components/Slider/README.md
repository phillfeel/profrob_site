# Slider

Ползунок калькулятора ROI: подпись и текущее значение крупно сверху, синий трек, шкала мин/макс моноширинным.

**Пропсы:** `label`, `min`, `max`, `step`, `value`/`defaultValue`, `unit`, `onChange(number)`.

- Значение форматируется с неразрывными пробелами: «12 000 м²».
- Пересчёт результата — мгновенно, без кнопки «Рассчитать».
