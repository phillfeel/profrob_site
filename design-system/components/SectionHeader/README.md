# SectionHeader

Шапка секции: моно-индекс «02 — РОБОТЫ», заголовок `display-l` с точкой и серый лид.

**Пропсы:** `index` («02»), `label`, `title`, `lead`, `align` (`start` | `center`), `as` (уровень заголовка, по умолчанию `h2`), `children` — например, кнопка справа.

- Заголовок — утверждение с точкой в конце, до 6 слов.
- Индекс совпадает с номером в SectionCounter.
