# SectionCounter

Моноширинный счётчик разделов «01 / 09» по правому краю экрана с синей шкалой прогресса.

**Пропсы:** `current`, `total`, `orientation` (`vertical` — по умолчанию, у правого края; `horizontal` — мобайл и слайдеры).

- Позицию (`position: fixed; right: space-10`) и обновление `current` по скроллу задаёт страница.
- Прячьте на ширине меньше 1024px — там счётчик переходит в горизонтальный в слайдерах.
