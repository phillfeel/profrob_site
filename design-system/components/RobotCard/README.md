# RobotCard

Карточка модели в каталоге: тёмное медиа-«мини-подиум» с тегом категории и кругом сканирования, производитель, название, характеристики моноширинным, цена и «Подробнее».

**Пропсы:** `tag`, `vendor`, `name`, `text`, `image` (PNG с прозрачным фоном, робот анфас/¾), `imageAlt`, `specs` — `[{label, value}]` 2–4 строки, `price`, `cta`, `href`.

- Фото — тот же студийный рендер, что в герое: белый корпус, мягкий верхний свет, без фона.
- Сетка каталога: 3 колонки на десктопе, 2 на планшете, горизонтальный скролл на мобайле.
- Данные в превью — пример заполнения.
