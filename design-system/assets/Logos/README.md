# Логотипы

Логотип условный — будет дорабатываться. Растровые PNG вырезаны с макета главного экрана, прозрачный фон; для прототипов, не для печати.

- `profrobot-logo.png` — знак + слово ПРОФРОБОТ, слово `ink`, знак `accent`. На `surface`, `surface-raised`, `glass`. Высота 24px.
- `profrobot-logo-inverse.png` — то же, слово светлое (`on-stage`). На `stage` и в тёмной теме: футер, сцена.
- `profrobot-mark.png` — только знак, синий `accent`. Фавикон, аватар, водяной знак на роботах. На светлом фоне.
